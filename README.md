# PROJECT 1.6

## Запуск сервера на Windows

Клонируем `.env.example` в `.env`: 

```shell
cp .env.example .env
```
Далее все по инструкции

На Windows сервер запускается, но подключение к нему через Docker Desktop может быть проблемным из-за сетевых особенностей. Поэтому сервер запускаем через **WSL + Docker**.

### 1. Установить WSL и Ubuntu

В PowerShell:

```powershell
wsl --install -d Ubuntu
```

После установки открыть Ubuntu:

```powershell
wsl -d Ubuntu
```

### 2. Включить интеграцию Docker Desktop с Ubuntu

В Docker Desktop:

```text
Settings → Resources → WSL Integration
```

Включить **Ubuntu**.

### 3. Скопировать проект в WSL

Создать директорию:

```shell
mkdir -p ~/projects
```

Скопировать проект:

```shell
cp -r /mnt/c/project1.6 ~/projects/
```

Перейти в проект:

```shell
cd ~/projects/project1.6
```

### 4. Запустить сервер

```shell
docker compose up -d --build
```

> **Важно:** контейнеры необходимо запускать из WSL, а не из Windows.

## Редактирование проекта из Windows

Проект хранится в WSL:

```text
~/projects/project1.6
```
В связи с этим, редактирование файлов на Windows ничего не даст, так как синхронизации между никакой нету. Чтобы обновить
сервер и запустить, надо заново копировать измененные файлы в WSL, только потом запускать. Надо подумать, что с этим
можно сделать
