## Запуск сервера на Windows

Клонируем [.env.example](.env.example) в `.env` и меняем то что хотим обновить: 

```shell
cp .env.example .env
```

Точно так же клонируем [users.example.ini](users.example.ini) в `users.ini` и меняем админов

**Далее все по инструкции, начинаем сборку образа**

На Windows сервер запускается, но подключение к нему через Docker Desktop может быть проблемным из-за сетевых особенностей. Поэтому сервер запускаем через **WSL + Docker**.

### 1. Установить WSL и Ubuntu

В PowerShell:

```powershell
wsl --install -d Ubuntu
```

После установки открыть Ubuntu:

```powershell
wsl -d Ubuntu
```

### 2. Включить интеграцию Docker Desktop с Ubuntu

В Docker Desktop:

```text
Settings → Resources → WSL Integration
```

Включить **Ubuntu**.

### 3. Скопировать проект в WSL

Создать директорию:

```shell
mkdir -p ~/projects
```

Скопировать проект:

```shell
cp -r /mnt/c/project1.6 ~/projects/
```

Перейти в проект:

```shell
cd ~/projects/project1.6
```

### 4. Запустить сервер

```shell
docker compose up -d --build
```

> **Важно:** контейнеры необходимо запускать из WSL, а не из Windows.
## Авторизация админов
Авторизация происходит по установке пароля в заголовке:

`setinfo "_ybpw" "123456"` - для админки Yapb
`setinfo "_pw" "123456"` - для админки Amxmodx

Но для удобства можно забиндить эти команды в файле клиента `/cstrike/userconfig.cfg)` и добавить еще парочку для удобства

`bind "F9" "amxmodmenu"`

`bind "F10" "yb menu"`

## Редактирование проекта из Windows

Проект хранится в WSL:

