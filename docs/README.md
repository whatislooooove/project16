# Здесь будет инфа по плагинам
### Команды, которые указаны здесь, надо собрать в 1 пункт меню!

#### Дефолтные команды
`yb menu` - управление ботами плагина Yapb
`amxmodmenu` - стандартная админка AMXMod. Будет включать в себя команды из некоторых плагинов
`project_botmenu` - кастомное меню. Пока можно убрать и вернуть ботов. При возвращении ботов учитывается конфиг `yb_quota` 
в [yapb.cfg](../server/cstrike/addons/yapb/conf/yapb.cfg)
